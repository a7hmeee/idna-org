# دليل تعبئة بيانات بلدية إذنا
## Municipality Data Collection Guide

---

## 1. Municipality (بيانات البلدية)

| الحقل | الوصف |
|-------|-------|
| **القسم المسؤول** | قسم تقنية المعلومات |
| **البيانات المطلوبة** | معلومات البلدية الأساسية (الاسم، الشعار، الموقع، بيانات الاتصال) |
| **اسم قالب الاستيراد** | `municipality_import_template.csv` |
| **الحقول الإلزامية** | `name_ar`, `name_en`, `email`, `phone`, `address` |
| **ملاحظات** | يتم استيراد سجل واحد فقط للبلدية. يتم تحديث البيانات بدلاً من إضافة سجلات جديدة. |

## إرشادات عامة

1. **تنسيق الملفات**: جميع ملفات CSV يجب أن تفصل بين الحقول بفاصلة `,` واستخدام علامات الاقتباس `"` للنصوص الطويلة.
2. **الترميز**: يجب حفظ الملفات بترميز **UTF-8 with BOM** لضمان عرض الأحرف العربية بشكل صحيح.
3. **التواريخ**: تنسيق التواريخ يكون `YYYY-MM-DD`.
4. **الحقول الاختيارية**: الحقول غير الإلزامية يمكن تركها فارغة.
5. **المراجعة**: يُرجى مراجعة البيانات قبل الاستيراد للتأكد من دقتها.
6. **الدعم الفني**: للاستفسارات والدعم الفني، يرجى التواصل مع قسم تقنية المعلومات.
